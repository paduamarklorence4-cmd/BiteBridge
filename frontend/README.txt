BiteBridge frontend (React + Vite)

1. Put the contents of this folder into BiteBridge\frontend (replace src, public, index.html, package.json, vite.config.js).
2. npm install
3. npm run dev   (http://localhost:5173)
4. Backend must be running on http://127.0.0.1:3000 (see .env).

Logo (optional): public/images/ez-animal-bite-center-logo.png  -> shown small in the navbar. If missing, a text wordmark is used.
Facebook: set VITE_FACEBOOK_URL in .env when the official page URL is confirmed.
Services: edit SERVICES in src/config.js and confirm them with the clinic.
